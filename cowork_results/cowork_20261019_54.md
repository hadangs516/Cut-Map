- 열 이름과 표 제목은 화면 구조에서 문구만 읽었고 숫자는 읽거나 옮기지 않았음. 저장한 html 안에는 표 숫자가 들어 있음

- 18번과 19번 사이에 브라우저 스크립트와 클릭 도구가 안전 확인 서비스 일시 오류로 거부되어 작업을 멈췄다가, 사용자 지시(10-19)로 19번부터 이어서 진행함. 이 때문에 16~18번 html은 먼저 저장하고 결과 파일은 20번까지 끝낸 뒤 이 파일에 함께 적음
- 19번부터 어디가 화면이 느려져 검색 대기 시간을 늘림. 경희대학교 검색은 처음 검색 버튼이 목록을 줄이지 못해 같은 검색을 한 번 더 한 뒤 선택함
- git 커밋, push, 스테이징은 하지 않았고 이 작업에서 git 명령을 쓰지 않았음
